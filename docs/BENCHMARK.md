# Benchmark

One artifact, thirty runs, three arms, one preregistered verdict. Everything on this page comes from
`web/bench/sprint-report.json`, which is in this repository; the dashboard renders it and recomputes
nothing.

## Design

- **Arms.** B = autonomous recovery with no Lifeguard. D = fixed guidance (a static instruction given
  to the worker). E = contextual Lifeguard (a message built from the actual block).
- **Pilot.** 10 scenarios × 3 arms × 1 repetition = 30 real runs against Vultr Serverless Inference,
  worker and guard both on `deepseek-v4.1-flash-1017`.
- **Scenarios.** GAU-023, GAU-024, GAU-029, GAU-012, GAU-021, GAU-001, GAU-027, GAU-032, GAU-034,
  GAU-044. Two of them (GAU-012, GAU-021) are negative controls.
- **Thresholds preregistered** before the data: 5 repetitions per cell, verdict `CONTINUE` only if
  one arm wins on resolved runs.

## Outcome

| Arm | Runs | Functional | Detected | Received | Resumed | Resolved |
|---|---|---|---|---|---|---|
| B | 10 | 5 | 1 | 0 | 0 | 0 |
| D | 10 | 5 | 1 | 1 | 0 | 0 |
| E | 10 | 5 | 1 | 1 | 0 | 0 |

Per scenario, all three arms behave identically:

| Scenario | State (B / D / E) | Note |
|---|---|---|
| GAU-012 | functional ×3 | negative control |
| GAU-021 | functional ×3 | negative control |
| GAU-023 | functional ×3 | |
| GAU-024 | functional ×3 | the only run with a real block: B detected and withheld, D and E sent a message |
| GAU-029 | functional ×3 | |
| GAU-001, GAU-027, GAU-032, GAU-034, GAU-044 | blocked ×3 | task never closed as resolved |

**Verdict: `INCONCLUSIVE`** — 1 of the 5 preregistered repetitions ran. That is a statement about the
size of the sample, not about the arms.

## What this does not show

- It does **not** show that the Lifeguard helps. In the single run where the message was received
  (GAU-024, arms D and E) the run was neither resumed nor resolved: receipt is the whole of what the
  guard achieved.
- It does **not** compare policy enforcement either, because the pilot never produced a gateway
  refusal. The policy surface is exercised by the test suite, not by this artifact.
- It does **not** support any claim about cost. The guard added 2,686 tokens in arm E; with one
  intervention that number is a curiosity, not a measurement.

## Reproducing

```sh
bun run bench        # deterministic benchmark: no network, no model, no cost
bun run check        # the test suite that exercises policy, gateway and sandbox
```

The live sprint runner (`bench/sprint-run.ts`, `bench/live.ts`) needs the scenario corpus and an
inference key; the corpus is intentionally not published (see the repository README). The runner is
public so the method can be inspected, not so the numbers can be regenerated byte-for-byte.
